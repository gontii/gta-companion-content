# Praca nad treściami GTA Companion

- To publiczne repozytorium treści. Nie zapisuj tu danych prywatnych, kodów
  dostępu, adresów testerów, sekretów ani notatek wewnętrznych Second Brain.
- Dokumentacja operacyjna po polsku; zachowuj język treści produktu.
- Pracuj na `main`, sprawdzaj Git przed edycją i zachowuj zmiany innych sesji.
  Stage'uj tylko zakres zadania; przed commitem sprawdź diff i `git diff --check`.
- Uruchamiaj `npm test`; dla zmienionych tygodni także walidację JSON.
  Nie oznaczaj niezweryfikowanych bonusów ani dat jako potwierdzonych.
- To repo publikuje treści do KV. Nie wykonuj stąd deployu aplikacji Pages.
  Skrypty publikujące i `smoke:weekly` wymagają odróżnienia od testów lokalnych.
- Zachowuj stabilne identyfikatory postępu i historyczne dane tygodni.
- Decyzje biznesowe i status projektu trafiają do `gontii/sb`, a nie do tego
  publicznego repozytorium.
